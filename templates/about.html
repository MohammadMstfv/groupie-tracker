THE PROJECT

About
Groupie Tracker.

A music directory for exploring artists, their members, and the places they have played.

What it does

Groupie Tracker brings four related datasets together into one place: artist profiles, concert locations, concert dates, and the relations that connect a location to an artist's dates.

Browse the artist directory, search by artist name or by details such as a member, place, date, or album, and open an artist to see their members and concerts grouped by location.

How it works

The Go server retrieves the public API datasets and joins them by artist ID. The browser requests search results and artist details from the server. Use Sync data to ask the server to refresh all four datasets concurrently.

The project uses Go's standard library for its server and data handling, with HTML, CSS, and JavaScript for the site.
