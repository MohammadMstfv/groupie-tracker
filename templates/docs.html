HOW TO USE THE SITE

Docs.

A quick guide to browsing, searching, and the data behind Groupie Tracker.

Browse artists

Open the artist directory to see artist cards with their image, activity start year, first album, and member count. Select any card to open its members and concert locations with related dates.

Search the catalog

Enter a name, member, place, date, or album in the search box. Results are separated by what matched: Artists, Members, Concert locations, Concert dates, and Artist details. Select any result to open that artist.

Filter artists

Set a minimum, maximum, or both for formation year, first album year, and member count. Select one or more concert locations; an artist matches if they have a concert in any selected place. Filters combine together, update the directory automatically, and can be removed with Clear all.

Explore concert locations

Open an artist card to see their concerts on a map. The server geocodes each concert location with OpenStreetMap Nominatim, caches coordinates for the current process, and respects its one-request-per-second usage policy. Markers are connected in date order; selecting one shows the location and concert dates. The concert list remains available if a location or the map service cannot be loaded.

Refresh the data

Select Sync data on the directory. The server fetches artists, locations, dates, and relations concurrently. The page checks the refresh status and reports whether the data was loaded.

Data sources

The public Groupie Trackers API provides the source data. The links below open the corresponding API endpoints:

  • Artists — profiles, names, images, members, and album information.
  • Dates — concert dates for each artist.
  • Places — locations associated with artists' concerts.
  • Relations — links concert locations to their dates.

Server endpoints

GET /
Artist directory.
GET /api/artists?q=...
Search by artist, member, location, date, or artist detail.
GET /api/artists?creationMin=...&creationMax=...
Filter by formation year, first album year, member count, and repeated location values.
GET /api/filter-options
Available numeric bounds and concert locations for the filter controls.
GET /api/artists/{id}
One artist, concert details, and asynchronously geocoded coordinates for map markers.
POST /api/refresh
Start a background refresh of all four API datasets.
GET /api/status
Check whether data is ready and a refresh is running.
